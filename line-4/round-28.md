# Pepe 28 — The Changed Lock

[SchemeCheck](tools/schemecheck/README.md) advances the unchanged OpenAPI
compatibility goal by checking authentication transport definitions as well as
symbolic requirements. Existing client requests may break when a same-named
scheme changes its API-key location/name, HTTP authentication method or type.
Alternative access methods are accounted for before a breaking finding is emitted.

```sh
python3 -B line-4/tools/schemecheck/schemecheck.py demo
```
